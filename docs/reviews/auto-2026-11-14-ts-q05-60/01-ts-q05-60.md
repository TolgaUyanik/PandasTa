# Task `ts-q05-60` — log and review rounds

## Implementation summary

Ported tsfresh's `quantile(q=0.05)` over 60 simple returns as
`pandas_ta/statistics/ts_q05_60.py`, column `TS_Q05_60`.

The module is six lines of arithmetic: mask a close that is not a finite,
normal, positive float; take the price RATIO minus one under
`errstate(over="ignore")`; drop a non-finite return; and call
`r.rolling(length, min_periods=length).quantile(0.05)`. `Q = 0.05` is a
module constant, not an argument, because the column name carries the `05`
(the `ts_imq_20` precedent). No dispersion floor and no magnitude bound —
both decisions are measured in `docs/TsQ0560Measured.md` §G3/§G4 rather
than argued.

Everything else is evidence. `docs/measure_ts_q05_60.py` has fourteen
sections (A1 A2 A3 A4 A5 A6 B M C D G O S Z) and produced every number in
the module docstring, the test docstrings and the receipt, bar the two the
receipt's header names (§D1's 1e+100 level and §F's pytest output).
