**The decisive read of the prototype.** It is
`sdiv(c - lo, up - lo)` where `sdiv(a, b) = _fin(a / b)` and
`_fin(x) = x.replace([inf, -inf], nan)`. So the prototype's ONLY guard is
`±inf → NaN`, and it does **not** mask a crossed band. That fixed two of the
three ASSUMPTIONs in `00-manifest.md` before any code was written: the module
is that expression plus the sibling's high/low `isfinite` masks, and nothing
else.

**Three things the measurement changed about what was going to be written**

* A first draft of §D claimed the column was *not* invariant under a level
  shift. The run refuted it: the shift cancels in numerator and denominator
  alike, so the column is invariant under any increasing AFFINE map of price —
  Spearman 1.0000 with matching NaN masks at +1, +50 and +1e6. The prose was
  rewritten to the measurement, and the measurement's own print was changed
  from `max |diff|` (which formatted 5e-5 as `0.0000`) to `max |rel|` in
  scientific notation so the next reader cannot be fooled the same way.
* A first draft of §F's prose said the close row "is the one to read" because
  the column is affine in close. The run refuted the pooled form of that:
  Spearman against close is −0.0112 … 0.5049. The ±1 is a WITHIN-STRETCH
  figure (§L) and is now stated as such, with the pooled figure printed
  next to it as the refutation.
* The §H collapsed-band hand frame as first written produced an all-NaN lower
  leg (the intended fractal low was its window's strict *maximum*). Caught by
  running it, replaced with a 16-bar frame where the low fractal confirms at
  exactly the high fractal's level, and the sibling's width is printed in the
  same table so the divergence is on the page.
