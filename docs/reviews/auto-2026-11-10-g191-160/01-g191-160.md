## Implementation summary

Ported GTJA191 alpha `#160` (`SMA(C<=C1 ? STD(C,20) : 0, 20, 1)`, scale-free `/close`) as
`pandas_ta/volatility/g191_160.py`, column `G191_160_20_20_1`. GTJA's own `SMA(A,n,m)` (an EMA
with `alpha=m/n`, NOT this fork's plain `sma`) implemented as `ewm(alpha=m/n, adjust=False,
