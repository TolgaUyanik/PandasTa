## 1. What it measures

Break of structure and change of character with the look-ahead removed (issue #332). The shipped
`bos` and `choch` flag a swing with a centred rolling window, so they use a swing before its
right-hand bars have printed. `bos_causal` registers a swing only on the bar where it becomes
knowable, and every column is a 0/1 flag: `BOSC_BULL_5` / `BOSC_BEAR_5` (close beyond the last
confirmed swing high / low), `BOSC_HH_5` / `BOSC_LL_5` (a confirmed swing beyond the previous one,
on the confirmation bar), `BOSC_CHOCH_BULL_5` / `BOSC_CHOCH_BEAR_5` (a break against the prevailing
swing trend). Evidence: `docs/BosCausalMeasured.md`. It ships beside `bos` and `choch`, which are
unchanged and still look ahead.

Seed, quoted from the module docstring:

```
Causal Break of Structure / Change of Character (bos_causal)
`bos` and `choch` with the look-ahead removed (issue #332). Both flag swings with `rolling(swing_length, center=True)`, so a swing is used `(swing_length - 1) // 2` bars before it can be known. Here a swing is registered only on the bar where its right-hand bars have printed.
```

## 4. Formula AS COMPUTED HERE

With `L = swing_length`, `k = (L - 1) // 2`, `left = L - 1 - k` (function `_confirm`): bar `j` is a
swing high iff `high[j] == max(high[j-left .. j+k])` and no later bar in `(j, j+k]` equals it
(rightmost tie wins); it is registered at bar `t = j + k`. Swing lows use the minimum and `low`.
`HH` / `LL` fire on that bar when the swing is beyond the previous confirmed one. `BULL` / `BEAR`
compare `close[t]` with the last swing confirmed at or before `t`. `CHOCH_*` run the `choch` trend
machine (a lower confirmed high sets a down trend, a higher confirmed low an up trend, a break against
it fires and resets to neutral) on the confirmed swings. Warm-up and NaN windows follow the module:
no swing is registered until a full window exists, and an all-NaN window registers none.
