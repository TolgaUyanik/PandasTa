# Equivalent strategies

Candidates that turned out to restate, or nearly restate, something the package already ships. Check this list
before porting a new candidate: if it is here, the work is already done.

| Strategy to be implemented | Existing equivalent strategy | Related GitHub issue |
|---|---|---|
| `b2_kvo_hlc3_34_55` — Klinger-style volume force oscillator, `VF = ±V` by hlc3 sign, `EMA34(VF) − EMA55(VF)` | `kvo` (`KVO_34_55_13`) — kvo's construction, not the same formula. Differences read in code include these. Ties: kvo signs a zero hlc3 change 0, the candidate gives +V. EMA seeding: kvo's `ema` starts from an SMA, the candidate's `ewm(adjust=False)` from the first value. The candidate also divides by `EMA55(V)`. Per-frame max median ρ 0.8986 vs `KVO_34_55_13` (stage-2 fork overlap on 12 frames, not Gate E; just under the 0.90 line). It also overlaps the MFI family: `MFI_Pctl` 0.7989 (prototype Gate E, run `screen_r8_20261026`) | [#192](https://github.com/TolgaUyanik/PandasTa/issues/192) |
| `b2_close_beyond_prev` — +1 if `close > high[t-1]`, −1 if `close < low[t-1]`, else 0 | `priorday_fib` — exactly `(PDFIB_HIGH > 0) − (PDFIB_LOW < 0)`; 0 mismatches on 36 synthetic tick-rounded frames (179,964 bars, 7,635 ties) | [#193](https://github.com/TolgaUyanik/PandasTa/issues/193) |
| `gate_e_backfill_333` — not an indicator: issue #333 asks for Gate E to be measured and recorded for six shipped modules (`HLIFE_100`, `EDGE_21`, `ARCHLM_100`, `LUMPINESS_100`, `DIFF2ACF1_100`, `FIRSTZEROAC_100`), with no new formula | `halflife` (`HLIFE_100`), `edge` (`EDGE_21`), `arch_lm` (`ARCHLM_100`), `lumpiness` (`LUMPINESS_100`), `diff2_acf1` (`DIFF2ACF1_100`), `firstzero_ac` (`FIRSTZEROAC_100`) — the candidates ARE these shipped modules: each is in `Category`, has its `core.py` accessor, and has a recorded `docs/gate_e_ledger.csv` row (runs `gatee7-20261115-*`, 2026-11-15, 687 comparators, 89 frames), all SHIP: 0.4209 vs `ADX` (n=359,496), 0.3889 vs `natr` (n=397,069), 0.1347 vs `natr` (n=389,949), 0.2122 vs `ZIGZAG` (n=32,790), 0.1323 vs `Swing_Range_pct` (n=390,038), 0.0542 vs `Swing_Range_pct` (n=389,949). `tests/test_gate_e_ledger.py` passes locally without `GATE_E_PENDING_OK` (1082 passed). No synthetic-frame comparison was run: comparing a module with itself is identity by construction | [#333](https://github.com/TolgaUyanik/PandasTa/issues/333) |
| `dti` — `HMU = max(high - high.shift(q-1), 0)`, `LMD = max(low.shift(q-1) - low, 0)`, `HLM = HMU - LMD`; `DTI = 100 * EMA_u(EMA_s(EMA_r(HLM))) / EMA_u(EMA_s(EMA_r(\|HLM\|)))` (EMA `ewm(span=n, adjust=False)`, a length of 1 skips that smoothing, 0 when the denominator is 0), q=2 r=20 s=5 u=3, bounded [-100, 100] | `smi` (`SMI_5_20_5`) — the same TSI ratio, `100 * EMA_5(EMA_20(close.diff())) / EMA_5(EMA_20(\|close.diff()\|))` (`tsi(close, fast=5, slow=20)`). DTI swaps the one-bar close change for the high-side minus low-side one-bar move and adds a third EMA of 3. Measured on 14 synthetic tick-rounded OHLCV frames (1,500 bars each, closes rounded to 0.1/0.01, highs/lows to 0.1, about 1.6% tied highs, first 100 valid bars dropped, about 1,381 rows per frame): per-frame median Spearman rho 0.9295 (min 0.9062, max 0.9525). Next closest: `tsi` at defaults (`TSI_13_25`) 0.9101, `adx` `DMP_14 - DMN_14` 0.9100, `rsi`/`cmo` 0.8507. A TSI on `hl2` (not shipped) reaches 0.9455. Synthetic frames, not Gate E. | [#265](https://github.com/TolgaUyanik/PandasTa/issues/265) |
| `dymi` — `sd = std(close, 5)`, `V = sd / SMA(sd, 10)`, `p = clip(int(14 / V), 5, 30)`; at each bar, over the last `p` close changes `d`, `DYMI = 100 * mean(max(d, 0)) / (mean(max(d, 0)) + mean(max(-d, 0)))` (simple mean, NaN when the sum is 0), recomputed every bar | `rsi` (`RSI_14`) — the same gain/(gain+loss) ratio on one-bar close changes, centred on the same pivot of 14. Differences in the code: `rsi` uses Wilder's RMA (`ewm(alpha=1/14)`), which runs on through the whole series, and a fixed length. The candidate uses a plain mean over a window of 5 to 30 bars that changes every bar with `std(close,5)/SMA(std,10)`. Measured on 14 synthetic tick-rounded close frames (1,500 bars each, ticks 0.01/0.05/0.1, Student-t(4) returns with volatility regimes, 619 zero-change ties, first 100 bars dropped, 19,600 rows in all): per-frame median Spearman rho 0.8719 (min 0.8546, max 0.8897). `cmo` (`CMO_14`, default `talib=True`, also RMA) is a monotone map of `RSI_14` and gives exactly the same rho. Non-default `RSI_10` gives 0.8861 and `RSI_7` 0.8571. The fixed-14 simple-sum form (`cmo(talib=False)`, not shipped) gives 0.8282, `RSX_14` 0.7838 and `STOCHRSIk_14_14_3_3` 0.5867. Synthetic frames, not Gate E. | [#262](https://github.com/TolgaUyanik/PandasTa/issues/262) |
| `dv2` — `u = SMA_2(close / ((high + low) / 2) - 1)`; `DV2_252 = count(j in t-251..t: u_j < u_t) / 252`, current bar counted in the 252, ties not below, NaN until 252 values of `u` exist, in [0, 1] | `cdvo` (`CDVO_10_2_126`) — the same Varadi construction (the close's stretch from the bar midrange `(high + low) / 2`, `SMA_2`, then a trailing percent rank). Three differences read in code (`pandas_ta/momentum/cdvo.py:34,61-66`): it divides the stretch by `ATR(10)` where DV2 divides by the midrange itself; it ranks against the 126 PRIOR bars, current bar excluded, where DV2 uses 252 bars with the current one included; and it reports [0, 100] where DV2 reports [0, 1]. Measured on 16 synthetic tick-rounded OHLC frames (1,500 bars each, ticks of 0.01 and 0.05, closes at the bar's high or low on 0.1%–8.9% of bars), 1,248 bars compared per frame: per-frame median Spearman ρ 0.9908 (range 0.9875–0.9940). With `rank_length=251` it is 0.9973 (range 0.9956–0.9978). Synthetic frames, not Gate E. | [#258](https://github.com/TolgaUyanik/PandasTa/issues/258) |
